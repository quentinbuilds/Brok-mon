# Gok-Mon

AI-native Game Boy-style monster-catching game for Arduino UNO Q + Summer Engine.

Open the Summer project at **`game/`**. Architecture and interfaces: [`docs/architecture.md`](docs/architecture.md).

Display is **480x800**. Source assets are **200x120**. Both live in [`game/config/game_config.gd`](game/config/game_config.gd).
